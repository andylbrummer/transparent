# Security policy

Transparent Earth is a static web app. It has no server, accounts or stored user data. It
asks the browser for your location and device orientation, and those stay on the device.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub instead: go to
the [Security tab](https://github.com/andylbrummer/transparent/security) and choose
**Report a vulnerability**.

Include what you found, how to reproduce it, and what it affects. You should get a reply
within a week.

## Supported versions

Only the latest version on `main`, which is what the live site serves, receives fixes.
